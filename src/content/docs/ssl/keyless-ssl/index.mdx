## 1) DNS (Cloudflare) — zona BIND pronta pra colar

> **O que corrige:** remove o apontamento errado para `www.fightzone.com.br` e acerta o `www` + root no seu host real.

```bind
;; Domain:     fightzone017.com.br.
;; Purpose:    Root e WWW entregando a MESMA página oficial.
;; Provider:   Cloudflare (com CNAME flattening no root)

$ORIGIN fightzone017.com.br.
$TTL 3600

@       IN  SOA lee.ns.cloudflare.com. dns.cloudflare.com. 2050806579 10000 2400 604800 3600
        IN  NS  lee.ns.cloudflare.com.
        IN  NS  perla.ns.cloudflare.com.

; --- WWW é o host oficial do site (origem hospedada) ---
; SUBSTITUA abaixo pelo SEU host de origem real (ex.: *.pages.dev, *.vercel.app, *.manus.space)
www     300 IN  CNAME  nghki1cz7nwl.manus.space.  ; cf_tags=cf-proxied:true

; --- Root usa CNAME flattening para entregar o MESMO conteúdo do WWW ---
@       300 IN  CNAME  www.fightzone017.com.br.    ; cf_tags=cf-proxied:true

; (Opcional) CAA — só emitir TLS por Let’s Encrypt
@       3600 IN  CAA 0 issue "letsencrypt.org"
@       3600 IN  CAA 0 issuewild "letsencrypt.org"
@       3600 IN  CAA 0 iodef "mailto:security@fightzone017.com.br"
```

**Notas rápidas:**

- Mantenha **DNSSEC** como já estava (DS na registradora). Se já tem DS publicado, **não mexa**.
- Em **Cloudflare → DNS**, deixe as nuvens **laranja (proxied)** no `@` e no `www`.
- Se seu host de origem **não** for `nghki1cz7nwl.manus.space.`, troque **somente** essa linha do `www`.

### 2.2 Worker de headers (HSTS, CSP, XSS, cache)

\`\` (Cloudflare Worker)

```js
export default {
  async fetch(request, env, ctx) {
    const resp = await fetch(request);
    // Clone headers
    const newHeaders = new Headers(resp.headers);

    // Segurança
    newHeaders.set('Strict-Transport-Security', 'max-age=31536000; includeSubDomains; preload');
    newHeaders.set('X-Content-Type-Options', 'nosniff');
    newHeaders.set('X-Frame-Options', 'SAMEORIGIN');
    newHeaders.set('Referrer-Policy', 'strict-origin-when-cross-origin');
    newHeaders.set('Permissions-Policy', 'geolocation=(), microphone=(), camera=()');

    // CSP enxuta (ajuste domínios se usar externos)
    newHeaders.set('Content-Security-Policy', [
      "default-src 'self'",
      "style-src 'self' 'unsafe-inline'",
      "script-src 'self' 'unsafe-inline'",
      "img-src 'self' data:",
      "font-src 'self' data:",
      "connect-src 'self'",
      "frame-ancestors 'self'"
    ].join('; '));

    // Cache estático básico
    if (request.method === 'GET' && new URL(request.url).pathname.match(/\.(css|js|png|svg|ico|webmanifest)$/)) {
      newHeaders.set('Cache-Control', 'public, max-age=31536000, immutable');
    }

    return new Response(resp.body, { status: resp.status, statusText: resp.statusText, headers: newHeaders });
  }
};
```

\`\` (rota do Worker)

```toml
name = "edge-headers-fz017"
main = "edge-headers.js"
compatibility_date = "2024-12-01"

[routes]
include = ["fightzone017.com.br/*", "www.fightzone017.com.br/*"]
```

> Publique com `wrangler deploy` e associe às rotas. Esse Worker **não** altera HTML, só **anexa headers** de segurança e cache.
